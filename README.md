## نبذة

**خِزانة** تطبيق ويب تقدّمي (PWA) يُثبَّت على الآيفون والأندرويد كأنه تطبيق أصلي، ويعمل بالكامل **بدون إنترنت وبدون خادم**. كل البيانات تُحفظ على جهاز المستخدم فقط، فلا حسابات ولا اشتراكات ولا إرسال لأي معلومة خارج الجهاز.

صُمّم للواقع العراقي تحديداً: الدينار والدولار بسعر صرف تحدده بنفسك، وبطاقات الرواتب والمحافظ الإلكترونية، والجمعيات الشهرية بنظام الأسهم، وإيجارات العقارات، والزكاة بالتقويم الهجري.

بُني ليجمع في تطبيق واحد ما تفرّق بين تطبيقات المصروف وتطبيقات دفاتر الديون، مع تقارير مفصّلة لكل قسم.

## المميزات

### 💳 المحافظ والحركات
- محافظ وبطاقات غير محدودة (كي كارد، ماستر، زين كاش، كاش، حساب مصرفي) لكل منها رصيدها وحركتها.
- عملتان: **الدينار العراقي والدولار** مع سعر صرف من الإعدادات، والتحويل بين المحافظ بعملتين مختلفتين.
- مصروف · دخل · تحويل، مع فئات جاهزة وإمكانية **إضافة فئة جديدة** من شاشة التسجيل مباشرة.
- حقل **«لمن؟»**: لي، للبيت، للعائلة، لشخص محدد من العائلة أو الأصدقاء — مع تحليل «لمن صرفت».

### 📌 الميزانية والالتزامات
- **التزامات شهرية ثابتة** (راتب للوالد، مولدة، إنترنت…) تُدفع بضغطة وتُخصم من الدخل.
- ثلاثة أساليب ميزانية حسب رغبتك: **صرف حر بالفئات**، أو **المظاريف** بحدود شهرية، أو **قاعدة 50/30/20**.
- **مصادر دخل** متعددة: الراتب، الإيجارات، عائد السيارة، أرباح الأسهم، وأي مصدر تضيفه.

### 👨‍👩‍👦 العائلة والأصدقاء
- إدارة الصرف على كل فرد من داخل حسابك، مع التزامات خاصة بكل شخص (راتب شهري، مشروع، دراسة…).

### 👥 الجمعيات
- **إدارة جمعية بنظام الأسهم:** نصف سهم، سهم، سهم ونصف، سهمان… مع توزيع دقيق للاستلام، واستلام مشترك لأكثر من شخص في الشهر نفسه.
- **قرعة إلكترونية** لترتيب الاستلام، بعشوائية آمنة وعرض متحرك.
- حالة كل عضو كل شهر: دفع · لم يدفع · **دفعتُ عنه** (يُسجَّل تلقائياً ديناً لك عليه).
- تحقق تلقائي من صحة التوزيع: مجموع الأسهم = عدد الأشهر، وكل دورة = سهم كامل.
- **جمعيات تشارك فيها:** القسط يُحسب ادخاراً، ومبلغ الاستلام لا يُحسب دخلاً.

### 🏢 العقارات
- أضف عقاراً بعدد المحلات والشقق والبيوت، فيُبنى لك **مخطط حيّ** للوحدات.
- لكل وحدة: المستأجر، الإيجار، يوم الاستحقاق، نهاية العقد، والتأمين.
- ألوان الحالة: مستلم · متأخر · لم يحن · شاغر، مع تنبيه بالعقود التي تقترب نهايتها.
- كل إيجار يُستلم يدخل تلقائياً في دخل الشهر وفي المحفظة التي تختارها.

### 🤝 الديون والأقساط
- لي عند الناس · عليّ للناس · مشتريات بالأقساط، مع جدول الأقساط والقسط القادم.
- التسديد من أي محفظة تختارها، و**كشف حساب لكل شخص** برصيد متراكم.
- **نسبة الأمان للمقترضين:** تقييم من 100 لكل شخص حسب سرعة سداده والتزامه بالمواعيد، مع نصيحة بالإقراض وأعلى مبلغ سدده بانتظام.

### 📈 الاستثمارات والأهداف
- أسهم، سيارة، ذهب، عقار، مشروع: رأس المال، القيمة الحالية، العوائد، ونسبة العائد.
- **أهداف ادخار** مع توقع موعد الوصول حسب معدل ادخارك، والمبلغ الشهري المطلوب إن حددت موعداً.

### 🤲 الصدقة الشهرية
- تحدد نسبة من دخلك أو راتبك، فيحسب لك مبلغ الصدقة كل شهر.
- سجل لكل صدقة: لمن، بماذا (نقد، طعام، ملابس، دواء…)، والتفاصيل، مع إحصائيات سنوية.

### 🕌 الزكاة
- حساب قائم على **موجوداتك الفعلية**: نقد المحافظ، مدخرات الأهداف، أقساط الجمعيات، الديون المرجوّة، الذهب بالوزن والعيار، الفضة، عروض التجارة، والاستثمارات.
- خصم الديون الحالّة عليك وأقساط الجمعيات المتبقية بعد الاستلام.
- **النصاب** بالذهب (85 غراماً) أو الفضة (595 غراماً) بسعر اليوم.
- **الحول القمري** بالتقويم الهجري (أم القرى) مع عدّاد الأيام الباقية.
- خيارات للمسائل الخلافية (زكاة الحُلي المستعمل، وخصم الديون) مع أحكام مختصرة، وسجل إخراج الزكاة لكل حول.

### 📊 الإحصائيات والتقارير
- رسوم بيانية تفاعلية في كل قسم: الدخل والمصروف، توزيع الفئات، التحصيل، الإشغال، العوائد.
- **تقرير لكل تبويب وتقرير شامل** لكل الأقسام، بفترة: أسبوع، شهر، سنة، الكل، أو فترة مخصصة.
- تصدير **PDF** بتنسيق عربي كامل، و**Excel** بورقة لكل قسم واتجاه من اليمين لليسار.

### ✨ الواجهة
- تصميم فاخر بالأخضر الزمردي والذهبي، مع **وضع ليلي ونهاري**.
- أرقام تُعدّ متحركة، وأشرطة تتحرك عند المرور أو اللمس.
- اختيار **الأرقام الإنجليزية أو العربية** (123 / ١٢٣) من الإعدادات.

## التثبيت على الهاتف

1. افتح الرابط **https://prog-alone.github.io/khizana/** في Safari (آيفون) أو Chrome (أندرويد).
2. آيفون: زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. أندرويد: القائمة ← **تثبيت التطبيق**.
3. يبدأ التطبيق ببيانات تجريبية للعرض؛ اضغط **«ابدأ ببياناتي»** أعلى الرئيسية لمسحها والبدء.

> أول تصدير PDF أو Excel يحتاج اتصالاً بالإنترنت مرة واحدة لتحميل أداة التصدير، ثم تعمل بدونه.

## البيانات والخصوصية

- كل البيانات محفوظة في **متصفح جهازك فقط** (localStorage)، ولا تُرسل لأي خادم.
- من **الإعدادات ← تصدير نسخة** احفظ نسخة احتياطية دورياً (في الملفات أو iCloud)، وبها تنقل بياناتك لجهاز آخر عبر **استيراد نسخة**.
- حذف التطبيق أو مسح بيانات Safari يحذف البيانات؛ لذا النسخة الاحتياطية مهمة.

## التقنيات

| الجانب | التفاصيل |
|---|---|
| الواجهة | HTML · CSS · JavaScript خالص في صفحة واحدة، بدون أي إطار عمل |
| التخزين | localStorage على الجهاز |
| العمل بدون إنترنت | Service Worker + Web App Manifest |
| الرسوم البيانية | SVG مرسوم يدوياً ومتوافق مع الوضعين الليلي والنهاري |
| التصدير | [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) لـ PDF · [SheetJS](https://sheetjs.com) لـ Excel (تُحمَّل عند الطلب) |
| الخطوط | IBM Plex Sans Arabic · Noto Kufi Arabic |
| التقويم الهجري | `Intl.DateTimeFormat` بتقويم أم القرى |
| الاستضافة | GitHub Pages |

## ملاحظة شرعية

حاسبة الزكاة مبنية على القواعد العامة المعتمدة عند المجامع الفقهية المعاصرة: ربع العُشر، والنصاب بالذهب أو الفضة، والحول القمري، وزكاة الديون المرجوّة وعروض التجارة، وعدم زكاة الأصول الثابتة المؤجَّرة. وتعرض الخيارات في المسائل الخلافية ليختار المستخدم ما يتبعه. في الحالات الخاصة يُرجع إلى أهل العلم.
